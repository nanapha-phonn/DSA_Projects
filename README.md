# Data Structures and Algorithms Projects

A collection of C++ projects designed to develop practical problem-solving skills and a deeper understanding of Data Structures and Algorithms (DSA). The projects are organized into three difficulty levels — **Beginner, Intermediate, and Advanced** — to support progressive learning, from fundamental programming concepts to more complex algorithms and system design.

The goal is to learn by building, understand how data structures work in practice, and improve the ability to write clear, efficient, and maintainable code.

## Learning Path

### 1. Beginner

**Focus:** Programming fundamentals and basic data structures.

These projects introduce essential concepts through small, manageable applications. The emphasis is on understanding program flow, working with data, implementing basic operations, and developing good coding habits.

Topics include:
- Arrays and strings
- Functions and modular programming
- Searching and sorting fundamentals
- Stacks and queues
- Basic linked lists
- File handling and input validation

**Example projects**
- Student Management System
- Online Examination System using Arrays
- Printer Queue Simulation
- Balanced Brackets Validator
- Bank Account Management using Linked Lists

### 2. Intermediate

**Focus:** Applying data structures to solve practical problems.

These projects combine multiple concepts and require more careful consideration of program structure, data organization, and algorithm selection. The emphasis is on writing reliable solutions and understanding the trade-offs between different approaches.

Topics include:
- Singly and doubly linked lists
- Circular linked lists
- Stacks and queues in application development
- Hash maps and efficient searching
- Recursion and tree traversal
- Breadth-First Search (BFS) and Depth-First Search (DFS)
- Basic time and space complexity analysis

**Example projects**
- Contact Book using a Linked List
- Phone Directory using a Hash Map
- Browser History Manager
- Music Playlist using a Circular Linked List
- Text Editor with Undo and Redo
- Maze Solver using BFS

### 3. Advanced

**Focus:** Algorithm design, optimization, and complex problem-solving.

These projects explore more challenging problems that require combining data structures, selecting suitable algorithms, and evaluating performance. The aim is to move beyond making a program work and understand why a solution works, how efficiently it runs, and where it can be improved.

Topics include:
- Trees, binary search trees, and heaps
- Graph algorithms and pathfinding
- Advanced sorting and searching
- Greedy algorithms and dynamic programming
- Algorithm optimization and complexity analysis
- Combining data structures to solve larger problems

**Example projects**
- Huffman Coding for File Compression Simulation
- Advanced Maze Solving and Pathfinding
- Priority-Based Task Scheduling
- Graph-Based Route Finding
- Algorithm Performance Comparison

*The examples describe the intended learning path; project availability and difficulty classifications may change as the repository develops.*

## Technologies

- **Version control:** Git and GitHub

## Getting Started

Clone the repository:

```bash
git clone https://github.com/nanapha-phonn/DSA_Projects.git
cd DSA_Projects
```

Navigate to a project directory and compile its source file. For example, if the project contains `main.cpp`:

```bash
g++ -std=c++17 main.cpp -o main
```

Run the compiled program:

**Windows**
```bash
.\main.exe
```

**Linux**
```bash
./main
```

The source filename and compilation command may vary by project. Check each project's files for any additional instructions or dependencies.
